# Refactor: Decompose team/page.tsx God Component

## Current State
- `src/app/team/page.tsx` — 854 lines, 6 inline reducers, 10+ async functions, 150+ lines of inline JSX for the detail view
- `src/hooks/useTeamPageReducers.ts` — **already exists** with all 6 reducers extracted, but page.tsx still duplicates them
- `src/components/team/LeaderDetailView.tsx` — **exists but empty** (0 lines)
- Existing team components (`BlockSelector`, `LeaderOrgChart`, `EntryForm`, etc.) are well-structured

## Problem
The page mixes data loading, state management, browser history, and 4 distinct view states into a single 854-line component. Changes to one view risk breaking others.

## Plan

### Step 1: Remove duplicated reducers from page.tsx
Delete lines 38-157 (the inline reducer definitions) and import from the existing hook:
```ts
import { useTeamPageReducers, emptyEntryForm } from "@/hooks/useTeamPageReducers";
```
This alone removes ~120 lines.

### Step 2: Extract `useTeamPageData` hook
Create `src/hooks/useTeamPageData.ts` to encapsulate all data loading and mutations:

**State to move:**
- `plantations`, `teamLeaders`, `selectedBlock`, `selectedLeader`
- `leaderEntries`, `leaderStats`, `leaderLatestEntries`
- `blockLastEntries`, `blockWorkersToday`
- `bijiRelaiEntries`
- `detailEntries`, `detailFilteredEntries`, `detailStats`

**Functions to move:**
- `loadData()`, `loadBlockStats()`, `loadLeaderData()`, `loadOrgChartData()`, `loadBijiRelai()`, `loadDetailData()`
- `handleSubmitEntry()`, `handleSubmitBijiRelai()`, `handleEditBijiRelai()`, `handleDeleteBijiRelai()`
- `handleSaveLeader()`, `handleDeleteLeader()`, `handleDeleteEntry()`
- `handleDetailSaveEdit()`, `handleDetailDeleteEntry()`

**Return:** All state + setters + functions that the page orchestrator needs to wire up views.

### Step 3: Extract `LeaderDetailView` component
Populate `src/components/team/LeaderDetailView.tsx` with the inline detail view JSX (lines 688-838).

**Props:**
```ts
interface LeaderDetailViewProps {
  leader: TeamLeader;
  detailEntries: DailyEntry[];
  detailFilteredEntries: DailyEntry[];
  detailStats: DetailStats;
  detailView: DetailViewState;
  detailViewDispatch: React.Dispatch<DetailViewAction>;
  onEditEntry: (entry: DailyEntry) => void;
  onDeleteEntry: (id: string) => void;
  onBack: () => void;
}
```

This removes ~150 lines of JSX from page.tsx.

### Step 4: Extract `useTeamHistory` hook
Create `src/hooks/useTeamHistory.ts` for browser history management (lines 451-486):
- `popstate` listener
- `pushState` calls on leader selection
- `prevBlockRef` tracking

**Return:** `pushLeaderHistory()`, `handlePopState` setup

### Step 5: Simplify page.tsx to orchestrator
After extraction, `page.tsx` becomes ~150-200 lines:
- Import and call `useTeamPageData()` and `useTeamHistory()`
- Call `useTeamPageReducers()`
- Wire up view switching (`AnimatePresence` + conditional rendering)
- Compose: `<BlockSelector>` → `<LeaderOrgChart>` → `<EntryForm>` / `<LeaderDetailView>`
